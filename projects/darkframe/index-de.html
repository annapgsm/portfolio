Dark Frame

Eine Movie-Discovery-App mit React und eigener API, gebaut rund um Suche, Login und gespeicherte Nutzerdaten.

React Node.js Express MongoDB React Router Redux JWT
Live Demo ↗ Source Code Client ↗ Source Code API ↗
Funktionen

Schnelle Suche und persönliche Filmlisten.

Live-Suche

Die Suche reagiert direkt beim Tippen und macht das Entdecken von Filmen schnell und unkompliziert.

Login und Registrierung

Nutzer können sich registrieren, einloggen und geschützte Bereiche über JWT-basierte Authentifizierung nutzen.

Gespeicherte Favoriten

Lieblingsfilme werden in der Datenbank gespeichert und bleiben auch über verschiedene Sessions hinweg erhalten.

Strukturierte Filmdaten

Jeder Film enthält Informationen zu Genre, Regie und Beschreibung, damit Nutzer gezielter stöbern können.

Frontend mit API-Anbindung

Inhalte und Nutzeraktionen sind mit einer REST API verbunden, sodass die Oberfläche direkt mit Backend-Daten arbeitet.

Wiederverwendbare Komponenten

Die Oberfläche ist aus modularen Komponenten aufgebaut, damit die Anwendung einfacher zu warten und zu erweitern bleibt.

Technischer Ansatz

Architektur & Stack

Dark Frame ist als Single-Page-Application mit klarer Trennung zwischen Frontend und Backend aufgebaut. Der React Client übernimmt Interface, Routing und Nutzerinteraktionen, während alle Daten über eine REST API geladen werden.

Im Backend ist die API in Routen und Datenmodelle strukturiert, damit die Codebase erweiterbar bleibt. MongoDB speichert Film- und Nutzerdaten, während JWT für geschützte Sessions und nutzerspezifische Inhalte genutzt wird.
