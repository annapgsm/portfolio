Dark Frame

A movie discovery app built with React and a custom API, combining search, authentication, and persistent user data.

Core Features

Fast search, secure access, and personalized movie tracking.

Real-Time Search

Search updates instantly as users type, making movie discovery fast and frictionless.

Authentication Flow

Users can register, log in, and access protected views through secure JWT-based authentication.

Persistent Favorites

Favorite movies are stored in the database, creating a personalized experience across sessions.

Structured Data Rendering

Each movie includes genre, director, and descriptive metadata to support deeper exploration.

API Driven Frontend

All content and user actions are connected to a REST API, linking the interface directly to backend data.

Resuable Component Structure

The interface is built from modular components, making the application easier to maintain and extend.

Technical approach

Architecture and Stack

DarkFrame is built as a single-page application with a clear separation between frontend and backend. The React client handles the interface, routing, and user interactions, while all data is loaded from a REST API. This keeps the app fast and responsive, with updates happening instantly without full page reloads.

On the backend, the API is structured into routes and data models to keep the codebase easy to extend. MongoDB stores user and movie data, while JWT authentication is used to securely manage user sessions.
