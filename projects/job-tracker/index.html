Job Tracker

A full-stack application that brings structure to the job search process, from saved roles to final offers.

Core Features

Turn a scattered job search into a clear, structured process.

Kanban workflow with drag & drop

Move applications between stages with drag and drop, with changes reflected instantly in the UI and synced to the database.

Board and table views

Switch between a visual board and a structured table depending on whether you want a quick overview or a more detailed comparison.

Optimistic UI updates

Interactions feel immediate by updating the interface first, while changes are confirmed with the backend in the background.

Smart search & filtering

Quickly narrow down applications through responsive search and status filters, without duplicating data across views.

Archive instead of delete

Archive applications instead of deleting them immediately, making it easier to clean up the workspace without losing important data.

Fully responsive across devices

Designed to work smoothly across desktop and mobile, with layouts and interactions adapted for smaller screens.

Technical approach

Architecture and Stack

The application is built as a seperated full-stack application, with a React frontend and a Node.js and Express API backed by MongoDB. Frontend and backend are deployed independently, reflecting a more realistic production setup.

On the frontend, state is managed centrally and filtered views are derived from the same dataset, which keeps the UI consistent across the board, table, and archive flows. To make the experience feel fast and responsive, updates are handled optimistically and then synchronized with the backend.

What I learned

Takeaways

Owning decisions end-to-end

This was the first project I planned and built independently after finishing my course, which meant making both technical and product decisions without a predefined path.

Designing around real workflows

Instead of treating the app as a collection of features, I focused on how people actually manage a job search and built the experience around that flow.

Keeping complexity manageable

Building multiple views, drag-and-drop interactions, and optimistic updates taught me how important clean state structure is as an application grows.
