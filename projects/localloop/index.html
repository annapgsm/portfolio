Core Features

Real-time messaging, offline access, and native mobile features in one app.

Real-Time Messaging

Messages update instantly using Firestore listeners, keeping conversations in sync without refresh.

Offline Support

Messages are cached locally, so users can still access conversations without a network connection.

Media Sharing

Users can take photos or select images from their device and send them directly in chat.

Location Sharing

The app can send a user's current location, display it as a map preview inside the conversation, and open it in Google Maps.

Network Handling

The app detects connection changes and adapts automatically between online and offline states.

Reusable Component Structure

The interface is built from modular components, making the application easier to maintain and extend.

Technical approach

Architecture and Stack

Chat App is built with React Native and Expo, using Firebase as the backend. Messages are stored in Firestore and updated through real-time listeners, so conversations stay in sync across devices.

The app also handles mobile-specific situations like unstable connections, media uploads, and location sharing. Messages are cached with AsyncStorage for offline access, while Firebase Auth manages users and Cloud Storage stores shared images.
