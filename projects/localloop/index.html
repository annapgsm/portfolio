Local Loop

A real-time mobile chat app for local communities, designed to make everyday coordination easier through messaging, media, and location sharing.

Core Features

A local-first chat experience for quick coordination, shared updates, and real-world moments.

Real-Time Community Chat

Messages update instantly with Firestore listeners, helping small local groups stay connected.

Offline Access

Conversations are cached locally, so users can still read recent updates when their connection drops.

Photo Sharing

Users can share quick visual updates, from a lost item to a notice in the building or a nearby event.

Location Sharing with Maps Integration

Current location can be shared, previewed in chat, and opened directly in Google Maps.

Connection-Aware Experience

The app detects network changes and switches between live updates and cached content automatically.

Native Mobile Interactions

Camera, image library, location, and map features are integrated through Expo and React Native APIs.

Technical approach

Architecture and Stack

Local Loop is built with React Native and Expo, using Firebase as the backend. Messages are stored in Firestore and updated through real-time listeners, so conversations stay in sync across devices.

The app also handles mobile-specific situations like unstable connections, media uploads, and location sharing. Messages are cached with AsyncStorage for offline access, while Firebase Auth manages users and Cloud Storage stores shared images.
