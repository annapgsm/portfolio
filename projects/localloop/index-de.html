Source Code ↗
Funktionen

Eine mobile Chat-Erfahrung für reale Nutzungssituationen.

Echtzeit-Chat

Nachrichten werden über Firestore Listener sofort aktualisiert, damit kleine lokale Gruppen einfach in Verbindung bleiben können.

Offline-Zugriff

Unterhaltungen werden lokal zwischengespeichert, sodass aktuelle Nachrichten auch bei instabiler Verbindung lesbar bleiben.

Fotos teilen

Nutzerinnen und Nutzer können schnelle visuelle Updates teilen – von einem verlorenen Gegenstand bis zu einem Aushang im Haus oder einem Event in der Nähe.

Standort teilen

Der aktuelle Standort kann geteilt, direkt im Chat angezeigt und anschließend in Google Maps geöffnet werden.

Verbindungsbewusste UI

Die App erkennt Netzwerkänderungen und wechselt automatisch zwischen Live-Updates und zwischengespeicherten Inhalten.

Native mobile Interaktionen

Kamera, Bildbibliothek, Standort und Kartenfunktionen sind über Expo und React Native APIs integriert.

Technischer Ansatz

Architektur & Stack

Local Loop wurde mit React Native und Expo entwickelt. Firebase übernimmt Authentifizierung sowie Daten- und Medienspeicherung. Firestore Echtzeit-Listener halten Unterhaltungen geräteübergreifend synchron, ohne dass Nutzerinnen und Nutzer manuell aktualisieren müssen.

Ein besonderer Fokus lag auf mobilen Nutzungssituationen wie instabilen Verbindungen, lokalem Caching, Medien-Uploads und Standortfreigabe. Aktuelle Nachrichten werden mit AsyncStorage gespeichert, während NetInfo der App hilft, auf Verbindungsänderungen zu reagieren.
